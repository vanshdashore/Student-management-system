# 🎓 Student Management System (Python + MySQL)

## 📌 Project Description

This is a simple Student Management System developed using Python and MySQL. It allows users to perform database operations like adding, updating, deleting, and searching student records.

## 🚀 Features

* Add new student
* View all students
* Update student details
* Delete student
* Find topper (highest CGPA)
* Search students by skill

## 🛠️ Technologies Used

* Python
* MySQL

## ▶️ How to Run

1. Import `database.sql` in MySQL
2. Open `main.py`
3. Run the Python file

## 📂 Files

* `main.py` → Python logic
* `database.sql` → Database structure
